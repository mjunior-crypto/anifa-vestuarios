# ANIFA VESTUÁRIOS 👕👗

## Bem-vindo ao nosso site de vendas online!

ANIFA VESTUÁRIOS é uma plataforma de e-commerce especializada em **moda para todas as idades**. Oferecemos uma ampla variedade de roupas de qualidade com excelente atendimento e múltiplas formas de pagamento.

### 📂 Categorias de Produtos
- **Infantil** - Roupas confortáveis para crianças
- **Adolescentes** - Moda jovem e moderna
- **Adultos** - Roupas elegantes e sofisticadas
- **Senior** - Conforto e estilo para a melhor idade

### 💳 Formas de Pagamento
- ✅ Cartão de Crédito (até 12x sem juros)

- Descrição detalhada de cada item

- Carrinho de compras funcional

---

## 📋 Como Usar

### 1. Navegação
- Use o menu superior para navegar entre as seções
- Clique em cada categoria para visualizar produtos específicos

### 2. Visualizar Produtos
- Clique em "Ver Detalhes" em qualquer produto
- Veja fotos, tamanhos, cores e descrição completa
- Escolha a quantidade desejada

### 3. Adicionar ao Carrinho
- Clique em "Adicionar ao Carrinho" no modal do produto
- Sua seleção será salva no carrinho

### 4. Finalizar Compra
- Clique no ícone do carrinho (canto superior direito)
- Revise seus itens
- Selecione a forma de pagamento
- Confirme a compra
